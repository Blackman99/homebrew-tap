# Blackman99/homebrew-tap

Homebrew formulae for Blackman99 projects.

```bash
brew install Blackman99/tap/renewhunt
```

| Formula | Project |
|---|---|
| `renewhunt` | [Blackman99/renewhunt](https://github.com/Blackman99/renewhunt) — hunt ACME renewal windows for 64-day certs |

Formulae are updated automatically by each project's release workflow.
